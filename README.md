# d2-ogre-kick

## 原理

| 阶段 | 操作 | 说明 |
|------|------|------|
| 1 | 飞升前走位 | W/A定位 → E插旗 → E吃旗 → 2切武器 → 冲刺走位 → 跳（严格按 .rec 录制回放） |
| 2 | 飞升分身 | X (Ascension) 留下克隆体吸引Boss仇恨 |
| 3 | S后退定位 | 飞升后 S×2 后退寻找输出位置 |
| 4 | ① ADS+近战 | 右键开镜瞄准 + C 近战拉怪 |
| 5 | ② 超能瞄准 | 第二次瞄准调正方向 |
| 6 | F 虚空超能 | Shadowshot: Deadfall 聚怪 |
| 7 | 冲刺终结 | A→W→SHIFT 冲刺 + G 终结技踢Boss |

## 环境

- Python 3.11 ~ 3.13
- Windows 10/11
- 屏幕分辨率 1920×1080
- 依赖：`pydirectinput`、`loguru`、`Pillow`（见 `requirements.txt`）

## 游戏内必设项

> ⚠️ 脚本对游戏内设置极其敏感，**只要任何一项不一致，鼠标偏移和时序就会全部跑偏**，必须严格按下方设置。

### 1. 画面设置

![画面设置](docs/images/03-display.jpg)

| 项 | 值 |
|---|---|
| 分辨率 | **1920 × 1080** |
| 窗口模式 | 窗口模式（无边界） |
| 帧率上限 | 165（启用帧率上限） |
| 视野 | **100** |
| 抗锯齿 | SMAA |
| 屏幕空间环境光遮蔽 | HDAO |

### 2. 键盘/鼠标设置 — 鼠标灵敏度

![鼠标设置](docs/images/01-mouse-sensitivity.jpg)

| 项 | 值 |
|---|---|
| 视角灵敏度 | **15** |
| 瞄准灵敏度调节 | **1.0** |
| 垂直/水平视角反转 | 不反转（默认） |
| 瞄准平滑度 | 关 |

### 3. 键盘绑定 ⚠️ 关键

![键盘绑定](docs/images/02-keybinds.jpg)

| 项 | 键 | 必设原因 |
|---|---|---|
| 向前/后/左/右移动 | W / S / A / D | 走位 |
| 充能近战 | **C** | 终结前置 |
| 跳跃 | Space | 飞升前跳跃 |
| 空中移动 | **X** | 飞升 |
| 终结技/互动玩家 | **G** | 终结 |
| 视角灵敏度 | 15 | — |
| ⚠️ **切换冲刺** | **Shift** | **必须设成"切换冲刺"，不能是"按住冲刺"！脚本 send Shift=按下立刻松开触发冲刺** |

> **重点：按住冲刺 必须保持空（"设置绑定"），把切换冲刺设成 Shift。**
> 否则脚本按下 Shift 时会触发"按住冲刺"模式，等脚本松开 Shift 又会把冲刺关掉，节奏完全错乱。

### 4. 设置界面本身的设置

进入游戏 → 按 **Esc** → **齿轮图标（设置）** → **键盘/鼠标** / **画面**。

### 5. 装备/护甲模组 ⚠️ 关键

![至高狂徒腿铠·强化运动](docs/images/04-leg-armor.jpg)

**腿铠（至高狂徒腿铠）必须插三个「强化运动」模组**（耗能 6/11，提升基础移动速度 +50、跳跃高度 +大幅）。

| 项 | 数量 | 原因 |
|---|---|---|
| 强化运动（腿铠） | **3 个** | 移动速度与跳跃高度直接决定飞升走位、S 后退、W→SHIFT 冲刺的**真实耗时**。如果换其他速度词条或减少数量，所有时序参数都会跑偏，需要重新录制 .rec 校准 |

> 三个强化运动叠加后角色移动速度远高于默认，手动都觉得"飞一样"的程度 —— 这就是脚本能精确压点的依据。如果只用 1~2 个，第 1 阶段飞升走位还没到位脚本就已经按 W 继续了，Boss 仇恨对不上、终结踢空。

## 安装

```bash
pip install -r requirements.txt
```

## 配置

编辑 `settings.toml`：

1. **[base]** — 按键绑定，按你在游戏里的设置修改
2. **[1080p]** — 鼠标偏移量与时序参数，基于录制数据校准
3. 所有参数都可在运行时用热键微调（F7/F1=切换参数、F2/F3=粗调、F5/F6=精调，改动立即生效并自动写回 `settings.toml`）

## 运行

双击 `start.bat`

f10 停止

## 使用教程（快速上手）

1. **进入游戏**：单人进图五壮举莫格斯，站在出生点的台子上，不动动鼠标和键盘
2. **确认游戏设置**：分辨率 1080p、鼠标灵敏度 15、Shift 设成「切换冲刺」、腿铠插三个「强化运动」（详见「游戏内必设项」）
3. **启动脚本**：双击 `start.bat`，左上角会弹出绿色状态框「● 等待启动」
4. **按 F8 启动**：脚本会回放飞升前序列 → 飞升 → 近战 → 虚空超能 → 冲刺终结，一轮约 30 秒
5. **自动循环**：脚本会自动检测 Boss 仇恨与位置，循环执行踢杀。左上角显示「R:N OK:N」（轮数 / 成功数）
6. **实时调参**：按 `F4` 列出所有参数；用 `F7`/`F1` 切换上/下一个参数；`F2`/`F3` 粗调（5×步长）、`F5`/`F6` 精调；改动**立即生效并自动写回 settings.toml**
7. **异常恢复**：连续失败 10 次脚本会自动自尽重生，等 `团灭后等待时间` 秒后重新开始
8. **终止**：按 `F10` 立即停止当前序列并清理按键；完全退出按 `Ctrl+C`

> 💡 第一次运行建议在 `settings.toml` 打开 `debug = true`，观察 `./debug/` 截图判断每轮是否正常进入 Boss 仇恨范围。

> **热键速查**：F8=启动 · F10=终止 · F1/F7=参数切换 · F4=列出全部 · F2/F3=粗调 · F5/F6=精调

## 调试

- 在 `settings.toml` 中设置 `debug = true`，脚本会在 `./debug/` 目录保存每次检测的截图，方便校准参数

## 注意事项

- 需要配装棱镜虚空猎 + 飞升星相 + 近战武器（取消枪的射击）
- Boss 两腿之间射箭 → 小怪聚拢 → **近战**触发终结血量 → 直冲终结
- 冲之前不要下台阶，否则 Boss 会提前抬脚
- 首次运行会先重置一次进度，确保在正确的出生点
